# Personality Checker

5つの質問に答えるだけで、あなたの性格傾向をかんたんにチェックできるシンプルな診断ツールです。

## 概要

Personality Checker は、直感的な質問への回答をもとに、あなたの考え方や行動の傾向をチェックするWebアプリです。

短時間で利用できるように、質問数は5問に絞っています。  
ちょっとした自己理解や、会話のきっかけとして使えるライトな診断ツールです。

## 特徴

- 5問だけで手軽に診断
- 4択形式で直感的に回答
- 回答の進捗をバーで表示
- 診断開始からの経過時間を表示
- スマートフォンでも見やすいシンプルな画面
- HTML / CSS / JavaScript のみで動作

## 使い方

1. 「診断をはじめる」ボタンを押します。
2. 表示される5つの質問に答えます。
3. 診断結果確認画面に進みます。
4. 結果画面で内容を確認します。

- HTML

外部ライブラリは使用していません。

## ローカルでの実行方法

このリポジトリをダウンロードまたはクローンし、`index.html` をブラウザで開いてください。

```bash
git clone https://github.com/your-name/personality-checker.git
cd personality-checker
```

その後、`index.html` を開くと利用できます。

## GitHub Pages で公開する場合

GitHub のリポジトリ設定から GitHub Pages を有効にすると、ブラウザ上で公開できます。

リポジトリ直下に `index.html` があるため、そのまま GitHub Pages に対応できます。

## プライバシーについて

このツールは、入力された内容をサーバーに送信したり、保存したりしません。  
すべての処理はブラウザ上で完結します。

## 注意事項

この診断は、娯楽・自己理解のきっかけを目的とした簡易的なものです。  
医学的・心理学的な診断を行うものではありません。
